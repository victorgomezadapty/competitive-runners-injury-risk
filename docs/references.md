# Sources and evidence hierarchy

Accessed for Milestone 1 on 2026-10-25. File-derived cohort/event/distribution results are generated locally, not copied from another analysis.

1. **Original replication release, authoritative for bytes and corrected lag order.** Lövdal S, den Hartigh RJR, Azzopardi G. Replication Data for: Injury Prediction In Competitive Runners With Machine Learning. [DOI 10.34894/UWU9PV](https://doi.org/10.34894/UWU9PV). Acquired Dataverse version 2.0, released 2024-06-05. [Metadata API](https://dataverse.nl/api/datasets/:persistentId/?persistentId=doi:10.34894/UWU9PV). Corrected [README, file 422690](https://dataverse.nl/api/access/datafile/422690?format=original), revision dated 2024-04-19. Publisher SHA-1 and local SHA-256 appear in `data/source_manifest.json`.
2. **Original study, authoritative for flag definition and sampling criteria.** Lövdal SS, Den Hartigh RJR, Azzopardi G. Injury Prediction in Competitive Runners With Machine Learning. *International Journal of Sports Physiology and Performance*. 2021;16(10):1522-1531. [DOI 10.1123/ijspp.2020-0518](https://doi.org/10.1123/ijspp.2020-0518), [PubMed](https://pubmed.ncbi.nlm.nih.gov/33931574/), [official university PDF](https://pure.rug.nl/ws/portalfiles/portal/183763727/_15550273_International_Journal_of_Sports_Physiology_and_Performance_Injury_Prediction_in_Competitive_Runners_With_Machine_Learning.pdf). Methods/Design pp. 1523-1524 resolve the initial 77 versus filtered 74. The consulted PDF contains the old daily suffix description, superseded by source README v2. Its original results, ROC-AUC 0.724 (Day) and 0.678 (Week), are historical benchmarks, not targets for tuning this project.
3. **Correction record.** *Erratum. Injury Prediction in Competitive Runners With Machine Learning*. IJSPP. 2024;19(8):846. [DOI 10.1123/ijspp.2024-0251](https://doi.org/10.1123/ijspp.2024-0251), [PubMed](https://pubmed.ncbi.nlm.nih.gov/38897576/). The corrected dataset README itself supplies our exact lag mapping; the erratum's existence is independently verified here.
4. **University metadata record.** [Publication portal](https://research.rug.nl/en/publications/injury-prediction-in-competitive-runners-with-machine-learning/) and [dataset portal](https://research.rug.nl/en/datasets/replication-data-for-injury-prediction-in-competitive-runners-wit/). The publication portal abstract still describes 77, so it must not replace direct file auditing.
5. **Recent methodological benchmark, not a preprocessing template.** Qiao T, Tian W. Explainable temporal deep learning for athlete-independent classification of injury-labeled days in competitive distance runners: a methodological benchmark using seven-day training-load histories. *Frontiers in Public Health*. 2026;14:1936365. [DOI 10.3389/fpubh.2026.1936365](https://doi.org/10.3389/fpubh.2026.1936365), [full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC13561803/). Relevant themes: athlete-disjoint evaluation, calibration, overlapping histories and recording artifacts. **Its Section 3.1 states unsuffixed Day -1 to suffix .6 Day -7, contrary to the original corrected README.** We follow the primary source and validate overlapping windows. Do not copy this lag map or assume its comparisons validate our pipeline.

The source replication notebook is downloaded for provenance and code inspection only. It is not run and its normalization, calibration, sampling and threshold procedures are not adopted. Complementary-source citations live in `complementary_dataset_review.md` with source-specific provenance.
